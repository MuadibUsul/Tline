# 研报实质内容闸门

## 原则

**发布的是研报，不是一个可抓取的页面。** 页面有标题、长度和摘要，不代表它有可核验的机构判断。占位页、导航页、登录/订阅页、错误页、纯目录页不进入公开层。

闸门分三层：

```text
确定性硬拦截 → 人工审核队列 → 判断模型（仅边界案例）
```

判断模型不是第一道门，也不单独决定下架。原因：

- “有参考意义”没有稳定数值标准，模型评分会漂移；
- 模型可能把“没有明确预测的宏观评论”误判为垃圾；
- 每次调用有成本和延迟，而占位页用规则就能识别；
- 下架是可逆的，但错误下架会损害内容覆盖，必须有可解释证据。

## 第一层：确定性硬拦截

命中任一项即 `indexable=false`，不调用模型。

| 规则 | 判定 | 例子 |
|---|---|---|
| 占位标题 | 标题归一化后等于 `ARTICLE COMING SOON`、`COMING SOON`、`文章即将发布`、`内容即将发布`、`敬请期待` | 已上线的 BNP `ARTICLE COMING SOON` |
| 占位正文 | 前 2,000 字符包含 `ARTICLE COMING SOON`、`文章即将发布`、`敬请期待` | 同一页面的正文和生成 PDF |
| 错误/门槛页 | 正文含 `page not found`、`access denied`、`login required`、`subscription required`、`cookies required`，且无可提取观点 | 付费墙、登录墙、404 壳 |
| 导航/样板页 | 去掉导航、菜单、订阅、登录、页脚后，实质正文不足 2 个段落或不足 300 字；或链接/短行占比过高 | 只有站点菜单、作者邮箱、栏目列表 |
| 无证据页 | `AtomicView = 0`、`keyArguments/keyNumbers/risks` 全空，且摘要本身在描述“没有分析/没有预测/即将发布” | 模型生成的“本页无法支撑结论” |
| 空文档 | PDF 只有封面/目录/免责声明/导航，文本量低于阈值，或正文页数为 0 | BNP 占位 PDF |
| 标题/URL 标签 | `PDF 777 Kb`、`Download the PDF`、`Untitled`、路径含 `article-coming-soon` | 已有标题规则继续保留 |

**当前实现**：`src/lib/contentQuality.ts` 的 `placeholder_content`，覆盖占位标题与正文标记。

## 第二层：人工审核队列

以下情况不自动发布，进入 `needs_review` / `noindex`，由运营确认：

- 没有 `AtomicView`，但正文很长、有明确段落；
- 有分析，但没有关键数字、目标价、风险或时间范围；
- 只有一家来源、标题过短、正文导航比例偏高；
- 判断模型给出 0/1 分或置信度低；
- 文档存在但 PDF 文本抽取失败。

审核界面需要展示：标题、机构、来源 URL、正文前 2,000 字、文档类型/页数、模型理由、命中规则。通过审核后写回人工决定和操作者，不静默覆盖。

## 第三层：判断模型（可选，仅边界）

### 评分定义

| 分数 | 含义 | 处理 |
|---|---|---|
| 0 | 占位、错误、登录/订阅、纯导航、营销页 | 不发布 |
| 1 | 新闻摘要/事件通知，无机构判断、无可核验依据 | 默认不发布或人工审核 |
| 2 | 至少一条可核验的机构判断、预测、目标价、风险或数据解释 | 可发布 |
| 3 | 多条判断 + 数字/期限/风险 + 明确来源 | 可发布 |

发布阈值建议：**≥2 自动通过；1 进入人工审核；0 直接拦截**。阈值必须用已标注样本校准，不能在未评估前上线。

### 模型输入/输出

输入只放必要内容：标题、来源 URL、正文前 2,000 字、结构化观点摘要、PDF 页数/文本量。不要在提示词里塞整篇长文。

输出固定 JSON：

```json
{
  "score": 0,
  "is_substantive": false,
  "reasons": ["placeholder_title", "no_claims"],
  "evidence": ["Article coming soon", "No forecasts or data"],
  "confidence": 0.95
}
```

把 `score`、`reasons`、`model`、`promptVersion`、`checkedAt` 存到 `Article`，不要只存一个布尔值。模型判断必须可追溯、可复核。

## 不用判断模型的替代方案

1. **占位/标题/URL 规则**：成本最低，当前 3 篇都能直接命中。
2. **正文结构规则**：去导航后的段落数、句子数、字数、链接密度、重复菜单行。
3. **证据提取规则**：要求至少一条 `AtomicView`，或非空的关键论点/关键数字/风险；没有则进入审核，不直接发布。
4. **PDF 检查**：页数、每页文本量、目录/封面特征；占位 PDF 直接拦截。
5. **来源级规则**：已知占位路径、RSS 标志、发布状态字段、站点地图/HTTP 状态。
6. **人工审核队列**：对“无量化观点但长文”的宏观评论最安全。
7. **来源白名单/黑名单**：只对已确认的出版商路径做补充，不作为唯一依据。

## 上线顺序

1. **已完成**：占位标题/正文硬拦截，重算存量，3 篇 BNP 占位页下架。
2. 增加导航/样板比例、实质段落数、空 PDF 检查；先 `--report` 只报告，不自动下架。
3. 对无 `AtomicView` 但有长正文的页面建立审核队列，默认不发布。
4. 用人工标注样本评估模型评分，先 shadow 运行，再决定是否让它影响发布。
5. 所有自动下架保留原始数据、URL、原因和操作记录，不做物理删除。
