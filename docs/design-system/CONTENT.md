# Tlines 内容与语言规则

## 编辑语气

- 先给结论，再给依据；不写营销式铺垫。
- 对机构观点使用“该机构认为/指出/预计”，不把机构观点写成 Tlines 的结论。
- 不确定时说清楚边界；不补造缺失证据。
- 中文和英文不是互相对照的“译文装饰”，两边都必须完整可读。

## 标题

- 页面主标题回答“这是什么”；编辑标题回答“为什么值得读”。
- 标题不使用全大写英文句子；系列名可以单独成行。
- 移动端标题优先保持语义完整，再考虑字号。
- 不把来源机构名称拼进标题来制造权威感；机构在 byline/来源中标注。

## 日期、数字、单位

- 日期使用页面 locale 的可读格式；机器可读结构使用 ISO 日期。
- 数字列使用等宽和 tabular numerals；百分比、基点、价格保留原文精度。
- 货币、单位、期限不擅自换算；需要换算时明确标注。
- 时间范围写清楚时区（例如北京时间/UTC）。

## 来源与可核验性

- 每条研报观点保留原始研报链接、机构、发布日期。
- 新闻注明来源；无法核验的内容不进入公开层。
- AI 生成或翻译的内容按现有 AI 使用说明标注，不伪装成人工原文。
- 更正信息保留原日期和更正说明，不静默改写历史。

## 中英文对等

- 英文页不得展示中文 fallback 作为正文；中文页同理。
- 新闻/研报的标题、导语、正文、备注在目标语言缺失时，应走既有补译/闸门流程，不在 UI 层临时拼接。
- 语言切换保留稳定 URL、canonical、hreflang 和完整文档加载。
- 专有名词按现有 `i18n` 词典处理；不要在每个页面另建译名。

## 可选内容与空态

- 空列表说明原因和下一步，不只写“暂无数据”。
- 备注/说明块不抢正文层级；能短则短。
- 不把“未找到”写成“系统错误”；不把“未配置”写成“无内容”。
