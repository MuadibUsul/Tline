# Tlines 设计基础

## 设计主张

**冷静、可核验的机构研究台。** 页面先让读者读到内容，再解释它从哪里来。

这不是一套通用后台皮肤，也不应被统一成 Linear 的复制品。保留 Tlines 自己的识别：

- 中性墨色表面 + 单一靛蓝行动色；
- 编辑衬线标题 + 系统无衬线正文 + 等宽数字；
- 低装饰边框、克制阴影、高信息密度；
- Light / Dark 双主题，但两者服从同一套语义角色。

## 页面原型

1. **编辑封面**（首页）：一条主报道 + 次级列表 + 机构观察/新闻侧栏。
2. **研究流**（`/research`）：筛选器、等宽卡片、统一右缘。
3. **长期阅读**（研报/新闻详情）：衬线标题、可读行长、来源与日期、结构化正文。
4. **政策/方法论**：1120px 主列 + 侧栏，正文优先。
5. **操作台**（`/admin`）：更高密度、更小字号，但仍使用同一组 token。
6. **系统页面**（登录、错误、空态）：不引入第二套视觉语言。

## 排版原则

- 标题用衬线是编辑身份，不用于界面控件。
- 正文行长优先于填满容器；列表卡片的正文可以占满内容列。
- 数字、日期、代码、期次使用等宽字体和 tabular numerals。
- 字号按角色取值（display / h1 / h2 / h3 / body / body-sm / meta / micro），不按页面临时决定。

## 颜色原则

- 靛蓝只承担行动、链接、选中态和信号，不做大面积装饰。
- 状态色必须带文字或形状，不能只靠颜色。
- 正文和辅助文字按 4.5:1；控件边界与焦点环按 3:1。
- 深色主题不是把浅色主题反相：主按钮在亮靛蓝上使用深墨字，避免白字失效。

## 布局原则

- 公共页最大内容宽度 1240px；政策页主列可扩展至 1120px。
- 卡片同宽是站主已确认的约束；文字多时只改变高度。
- 列表行共用同一右缘；不要用 `70ch` 之类的局部限宽制造空白缺口。
- 移动端 320px 必须可用，不产生横向滚动。

## 禁止事项

- 不引入 Tailwind、Radix Themes、shadcn 或第二套组件库。
- 不在组件里写新的十六进制颜色；先加 token，再使用。
- 不删除既有 class API；先加别名，逐页迁移。
- 不把“看起来更现代”当成验收；每个视觉变更必须有对比度、键盘或截图证据。
