# 行情与宏观预期方法说明

## 数据分类

- 研究观点共识：文章观点聚合，不是价格或市场调查预期。
- 市场一致预期：有来源、授权、采集时间且在发布前可得的调查值。
- 模型预测：供应商、央行或本站模型输出，单独标识。
- 实际观测：供应商市场报价或官方首次公布/修订宏观值。

缺失始终是空值并附原因，不是 0。前值不补共识，LLM 不补数字、样本量或统计结果。

## 行情口径

身份匹配至少包含内部 instrument、供应商 symbol、场所、报价币种、工具类型、单位和价格类型。BTC/USD 与 BTC/USDT、黄金现货与期货、现货原油与连续合约均不等价。相同来源与口径的历史序列才可计算变化；代理资产不得精确结算目标价。

新鲜度同时考虑观测时间、供应商更新时间、接收时间、采样间隔和市场开闭。休市允许更长有效窗，但不会把旧报价重写成刚更新。30 分钟采样只表示本站采样频率，不代表供应商延迟，也不支持精确 5 分钟事件反应。

## 预期、surprise 与结算

发布时只冻结完全匹配且获授权的发布前版本。raw surprise = 首次实际值 − 冻结市场调查共识；无共识返回空值与原因。模型差和机构研报分布独立展示。预测结算只使用明确时间窗内、同来源/领域/单位/价格类型的非代理市场观测，并保留起终证据 ID 与规则版本。

## 用途授权

内部分析、公开展示、API、社交和衍生展示分别授权。许可 UNKNOWN 时一律关闭对应数字。衍生变化不自动继承再分发许可；必须在 `DataLicensePolicy.allowedUses` 中明确允许。
