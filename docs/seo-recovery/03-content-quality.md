# 03 · 研报内容质量与可核验性

审计日期：2026-10-09（Asia/Shanghai）

范围：当前开发数据库、现有入库/分析/发布链路、研报详情与资产比较页

约束：只读审计；未部署、未修改生产数据库、未批量删除或 `noindex` 既有页面。

## 结论

本阶段将“更多 AI 文字”改成了“字段必须有证据，否则明确缺失”。新分析写入前会同时检查自由文本与预测字段；无法在原文确认的目标值会被清空，分析进入 `needs_review`，不会因为模型填满 JSON 就成为可索引页面。既有 436 篇记录只做了只读审计，数据库门禁状态没有被批量改写。

最重要的现状是：现有句级证据质量很好（2,099/2,099 条 `sourceQuote` 可在正文中找到），但历史自由文本和资产预测仍有明显积压。367 份分析中，149 份通过本次保守规则；主要差距是 169 篇资产观点的时间范围无法逐字或按受支持格式回查，需抽样区分旧模型推断和格式差异。69 篇没有分析，45 篇本来已处于待复核。版权展示权限没有被数据模型记录，因此不能把 `crawlPolicy=allowed` 当作全文/PDF再发布授权。

## 已实施的规则

### 1. 新内容结构化门禁

`src/lib/ingest/researchQuality.ts` 在模型输出进入数据库前验证：

- 核心结论不能直接复制正文首句并冒充 Tlines 结论。
- 结论、论据、数字、风险和解读不能包含免责声明、订阅、广告或菜单文案。
- 自由文本中的数字、实体、确定性措辞与年份必须在原文中有依据。
- 目标值必须同时具备原文中的目标语义、数值、单位和时间范围。
- 当前 `ArticleAsset` 尚无单位字段、页面历史上按美元展示，因此本阶段只允许明确的 USD 目标进入该字段；EUR、JPY、指数点、利率和商品单位目标留空并待复核，绝不换算或假定为美元。
- 缺失或不支持的字段被清空，不使用发布日期推断预测年份。
- 任一上述问题使新分析成为 `needs_review`；现有发布门禁会暂缓该新内容公开。

模型提示版本已由 `analysis-evidence-v1` 升为 `analysis-evidence-v2`，明确要求“不确认就返回 null”。历史记录没有自动重跑。

一份结构完整但未通过确定性规则的模型响应会直接进入待复核，不再为同一来源自动购买第二次全上下文生成；只有 JSON 损坏或必填输出缺失才升级重试。这同时降低 DeepSeek 等分析路由的重复调用开支。

### 2. 规则提取不再伪装成“一句话结论”

旧的无模型回退会截取正文前 42 个词作为 `summary`。现在只选择满足观点规则且与 `sourceQuote` 完全相同的证据句；找不到证据句就留空并进入待复核。

详情页按来源区分三类内容：

- 机构原文证据摘录：带引号，明确是机构措辞。
- 自动译文摘录：明确不是机构原话，也不是 Tlines 结论。
- Tlines 自动提取结论：明确不是机构措辞，并要求回原文核验。

页面同时显示研究主题、机构、发布日期、时间范围、关键数字、风险、最多三条原文证据及数据缺失状态。没有关键数字或风险时显示“未明确给出”，不再用空白暗示存在数据。

### 3. 比较分析的边界

- 研报页用现有 `ArticleAsset` 数据显示机构、发布日期、方向、可核验目标与时间范围。
- 有其他机构数据时才称“多机构观点对比”；只有一家机构时明确标为“单机构观点”，并声明不是市场共识。
- 目标价分布至少需要两家不同机构、两个带时间范围的有效目标；单一目标或无日期目标不再生成分布。
- 研报卡片、机构当前观点、资产贡献表、目标分布和观点历史在展示前都会用对应正文再次校验历史目标；旧数据中无法回查的目标显示为空。
- 预测结算同步同样执行来源校验；不通过的记录写入 `excluded / unverified_source_claim`，不进入命中率统计。该逻辑本阶段仅提交代码，未运行生产同步。
- 现有资产页的机构历史变化仍由 `getAssetTimeline` 提供；本阶段没有生成新的叙事性 AI 文案。

### 原始 URL 实测

对回归样本中的 20 个真实来源做了 HEAD/小范围 GET 检查：19 个返回成功状态，2 个发生重定向，1 个返回 403。

- Julius Baer 样本返回 403：可能是机器人策略，并不证明页面不存在，标记“待浏览器/授权策略验证”。
- ING `german-construction-is-turning-the-corner...` 重定向到文章列表页：疑似来源失效或软 404，应人工修正来源。
- Intesa Sanpaolo PDF 重定向到免责声明页：来源存在，但访问需要先经过免责声明流程。

网络检查结果会随来源站变化，不进入自动 `noindex` 决策。

## 修改前后案例

| 场景 | 修改前 | 修改后 |
|---|---|---|
| 无模型摘要 | 正文前 42 个词被当作“一句话结论” | 只使用完整、可回查的观点证据句；没有则留空并待复核 |
| `$4,900` 目标无期限 | 保存 4,900，页面可能展示为目标价 | `target=null`，`needs_review`，页面显示未明确 |
| 模型输出 `2027`、原文只有 `2026` | 年份因数字检查忽略四位年份而可能通过 | `forecast_year_unsupported` |
| 免责声明成为风险/结论 | 只做数字/实体检查，可能通过 | `boilerplate_in_analysis` |
| 一家机构一个目标 | 也可能生成最低/中位/平均/最高分布 | 只显示单机构观点，不生成分布、不称共识 |
| 研报证据 | 页面只有结构化字段和整篇原文 | 结构化字段旁显示最多三条对应原文证据并注明来源性质 |

## 优先级与人工决定

### P0 · 已修复（新内容）

- 无依据数字、实体、确定性措辞和年份进入新分析。
- 目标值缺单位、期限或原文依据仍被保存/展示。
- 规则回退用正文开头伪装成结论。
- 单机构目标被包装成目标价分布或市场共识。

### P0 · 需要人工决定

- **原文展示权限**：`Institution`/`Article` 没有记录研报全文或 PDF 的公开展示授权。`crawlPolicy` 只证明抓取政策，不能证明再发布权。请逐机构确认：仅链接、短摘录、内嵌 PDF、全文展示分别允许到什么程度。在确认前不应扩大原文转载。
- **非 USD 目标单位模型**：当前 `ArticleAsset` 没有 `targetUnit`。本阶段安全策略是留空；若业务要比较 EUR、JPY、指数点或商品单位，应先增加单位字段和同单位比较规则，不能用美元符号代替。

### P1 · 人工复核队列

- 先处理 4 个损坏标题、3 个混入模板文案、11 个目标无法回查、2 个缺单位目标及 1 个疑似失效来源。
- 31 个年份异常应对照标题、表格和 PDF 后决定；规则命中不是自动删除依据。
- 对 169 个时间范围异常先按机构和格式抽样，确认 `1M/3M/12M` 等旧模型标签是否确有原文依据；未完成评估前不批量改门禁。
- 14 个首段复制记录应改为“原文摘录”或重新生成有证据的 Tlines 提取结论。
- 既有 45 个 `needs_review` 保持原状态；不要运行批量 `--apply` 或批量重解析，除非完成抽样评估和成本预算。

### P2 · 数据覆盖

- 当前快照没有中文原始研报，只有英文原文与中文翻译。若中文原始机构研究是产品目标，需要先接入并单独评估中文提取规则。
- 来源实测的 403、免责声明跳转和软 404 需要建立按机构的验证策略，不能把所有非 200 一律视为内容失效。
